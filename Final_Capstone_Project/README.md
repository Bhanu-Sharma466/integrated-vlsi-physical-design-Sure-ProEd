<h3 id="project1">Project 1: RISC-V Processor: RTL-to-GDSII Physical Design Implementation </h3>
<p>
 This project demonstrates the end-to-end physical design implementation of the PicoRV32 32-bit RISC-V processor, starting from RTL and progressing through synthesis to the final routed layout.

The project was implemented using an open-source ASIC physical design flow based on OpenLane, OpenROAD, and Yosys, targeting the SKY130A 130 nm process technology.

The primary focus of the project is to understand and analyze how different physical-design stages and implementation parameters affect timing, area, routing, clock distribution, and power integrity.
</p>

## **Learnings from LST and SST**

Soft Skills & Professional Development
Beyond technical implementation, the Life Skills Training (LST) and Soft Skills Training (SST) sessions focused on the operational and interpersonal competencies needed to transition smoothly into an engineering environment.

Personal Discipline & Ownership
Developing consistent work habits and structured time management proved essential during project execution. The emphasis was on taking end-to-end ownership of deliverables, maintaining accountability for both successes and technical bottlenecks, and managing project milestones systematically.

Communication & Technical Articulation
Technical execution requires clear articulation to be effective. The sessions focused on structuring complex concepts clearly for different audiences, practicing active listening to gather requirements accurately, and ensuring team alignment to prevent miscommunication during handoffs.

Collaborative Negotiation
Negotiation was framed as an objective problem-solving tool rather than a competitive argument. Key takeaways included managing project constraints (such as deadlines, resource limits, and trade-offs) by evaluating options logically and striving for alignment that serves overall project goals.
